AI로 문장 다듬기 설정

키가 없어도 계획서 만들기와 인쇄는 모두 됩니다. Claude API 키를 넣으면 2단계에 AI로 문장 다듬기 버튼이 생겨요.

  • 키는 이 컴퓨터의 이 브라우저에만 저장돼요. 다른 선생님께 파일을 보내도 키는 함께 가지 않아요.
  • 버튼을 누를 때마다 API 사용 요금이 키 주인에게 청구돼요.
  • 공용 컴퓨터에서는 사용 후 '키 지우기'를 눌러 주세요.
