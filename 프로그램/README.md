# 프로그램 서포터

지역아동센터 선생님을 위한 **프로그램 계획서 · 일지 · 평가서 작성 도우미**입니다.
프로그램 형태와 분야, 대상만 고르면 숫자 목표가 들어간 계획서를 만들어 줍니다.
같은 내용으로 일지와 평가서도 자동으로 채워져서, **계획 → 실행 → 평가** 서류를 한 번에 끝낼 수 있습니다.
안내 캐릭터 **별이**(노란 승합차)가 단계마다 할 일을 알려 줍니다.

---

## 1. 시작하기

### PC (권장)
1. `프로그램서포터.html` 파일을 **더블클릭**합니다. 크롬이나 엣지에서 열립니다.
2. 설치할 것은 없습니다. 다른 선생님께는 **이 파일 하나만** 보내면 됩니다.

### 휴대폰
- **웹 링크**: https://claude.ai/artifact/FQd8kV7FpQSaigkoZdm94P
  - 내용 확인과 작성은 할 수 있지만 **인쇄와 파일 저장은 되지 않습니다.**
- **안드로이드**: HTML 파일을 받아 크롬으로 열면 PC와 똑같이 쓸 수 있습니다.
- **아이폰**: 파일을 바로 열면 버튼이 작동하지 않을 수 있으니 웹 링크를 쓰세요.
- 휴대폰에 작성한 내용은 그 휴대폰에만 저장됩니다. 인쇄할 서류는 PC에서 작성하세요.

## 2. 사용 순서

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| **1. 내용 고르기** | ① 형태 → ② 분야 → ③ 학년·인원 → ④ 일정 → ⑤ 아동 특성·요청 | 1~2분 |
| **2. 계획서 확인** | 만들어진 칸을 읽고 필요한 곳만 고치기. 예산 쓰기 | 3~5분 |
| **3. 서류 만들기** | 계획서 / 일지 / 평가서 중 골라서 인쇄하거나 워드로 저장 | 1분 |

### ① 프로그램 형태
| 형태 | 예 | 만들어지는 일정 | 일지 |
|---|---|---|---|
| 정기 프로그램 | 미술교실, 독서, 학습지도 | 회기별 날짜·주제·활동 | 회기마다 1장 |
| 하루 행사 | 나들이, 체육대회, 발표회 | 당일 시간표 | 1장 |
| 숙박 캠프 | 여름 캠프, 졸업 여행 | 1일차·2일차… 시간표 | 날짜마다 1장 |

### ② 분야 (지역아동센터 5대 영역, 키워드 18개)
| 영역 | 키워드 |
|---|---|
| 보호 | 요리, 생활습관, 안전교육 |
| 교육 | 독서, 학습지도, 과학, 코딩·디지털, 보드게임, 진로, 미술, 음악, 체육·놀이 |
| 문화 | 나들이·체험, 행사·축제 |
| 정서지원 | 정서·마음, 또래관계, 가족 참여 |
| 지역사회연계 | 지역 탐방·봉사 |

목록에 없으면 직접 쓸 수 있습니다. (기본 틀로 만들어지니 활동 내용을 꼭 고쳐 주세요.)

### ③ 학년·인원
- 학년은 여러 개 고를 수 있고, `전체`를 누르면 초1~중학생이 한 번에 선택됩니다. (계획서에는 '전체 아동'으로 적힙니다)
- 인원은 `−` `+` 버튼을 누르거나, **숫자를 눌러 키보드로 바로** 고칠 수 있습니다. (1~200명)
영역의 중분류(예: 교육 → 학습 / 특기적성 / 성장과 권리)는 2단계에서 바꿀 수 있습니다.

### 2단계에서 꼭 볼 것
- **목표 아래 '근거'**: 숫자를 어떻게 정했는지 적혀 있습니다. 예) 참여 인원 12명 × 80% = 10명
- **하루 행사·숙박 캠프**는 장소 칸이 비어 있으니 꼭 채워 주세요.
- 1단계 ⑤에 쓴 '운영 방법에 꼭 넣을 내용'은 운영 방법에 한 줄씩 들어갑니다.

### 3단계 서류별 안내
- **계획서**: 아동 만족도 조사지(얼굴 그림 5점 척도)를 함께 인쇄할 수 있습니다.
- **일지**: 회기(날짜)를 고르면 진행내용이 미리 채워져 있습니다. 참여자, 담당자 의견, 사진만 넣으면 됩니다. '전체 한 번에'로 모든 일지를 한꺼번에 인쇄합니다.
- **사진**: 일지 1장에 **8장까지** 넣을 수 있고, 여러 장을 한 번에 골라도 됩니다. 사진을 넣으면 **모자이크 창**이 열립니다. 가릴 곳(얼굴, 이름표)을 마우스나 손가락으로 끌어서 네모를 그리면 그 부분이 모자이크됩니다. 여러 군데를 가릴 수 있고 `한 번 되돌리기`로 취소할 수 있습니다. 나중에 사진 위 `모자이크` 버튼으로 다시 고칠 수도 있습니다.
- **평가서**: 목표마다 `달성 / 일부 달성 / 미달성`을 누르고 결과를 씁니다. 만족도 조사 응답 수(문항별 1~5점에 몇 명)를 넣으면 **평균, 4점 이상 비율, 막대그래프**가 자동으로 들어갑니다.
- **결재란**: `담당자 · 시설장`, `담당 · 센터장`, `담당자 · 사무국장 · 시설장` 중에서 고르거나, **직접 고치기** 칸에 `담당/센터장`처럼 `/`로 나눠 쓰면 그대로 바뀝니다.
- 비워 둔 칸은 손으로 쓸 수 있게 빈칸으로 인쇄됩니다.

## 3. 인쇄와 저장

### 인쇄 설정 (중요)
| 항목 | 설정 |
|---|---|
| 용지 크기 | **A4** |
| 여백 | **기본값** |
| 배율 | **기본값 (100%)** — '페이지에 맞춤'으로 바꾸지 마세요 |
| 머리글과 바닥글 | **끄기** (날짜·주소가 같이 찍히는 것을 막습니다) |
| 배경 그래픽 | 켜기 (표 제목 칸 회색, 만족도 막대그래프가 나옵니다) |

- **PDF로 저장**: 인쇄 창에서 프린터를 `PDF로 저장`으로 바꿉니다.
- 회기가 많으면 계획서가 2장으로 이어집니다. 표는 잘리지 않고 다음 장에 이어서 나옵니다.

### 워드(한글) 파일로 저장
- 3단계 아래 `워드(한글) 파일로 저장`을 누르면 지금 보고 있는 서류가 `.doc` 파일로 다운로드 폴더에 저장됩니다.
- 워드와 한글에서 열어 더 고칠 수 있습니다.
- 사진과 얼굴 그림은 워드 파일에 들어가지 않습니다. 사진이 필요하면 인쇄나 PDF를 쓰세요.

## 4. 저장과 개인정보

- 작성 중인 내용, 센터 이름, 담당자 이름은 **그 컴퓨터의 브라우저에 자동 저장**됩니다. 창을 닫았다 열면 `이어서 고치기`로 계속할 수 있습니다.
- 다른 컴퓨터나 다른 선생님에게는 저장 내용이 전달되지 않습니다.
- 브라우저의 '인터넷 사용 기록 삭제'를 하면 작성 중이던 내용도 지워집니다. 다 쓴 서류는 PDF나 워드로 남기세요.
- 아동 이름과 사진이 공용 컴퓨터에 남지 않게 주의해 주세요. 사진은 모자이크 창에서 얼굴을 가려서 넣는 것을 권합니다.
- 사진이 많으면 브라우저 저장 공간이 모자랄 수 있습니다. 그때는 화면에 안내가 나오고, 인쇄는 그대로 됩니다.

## 5. AI로 문장 다듬기 (선택)

- 키가 없어도 모든 기능을 쓸 수 있습니다. AI는 문장을 더 자연스럽게 고쳐 주는 **추가 기능**입니다.
- 오른쪽 위 `AI 설정`에 Claude API 키를 넣은 컴퓨터에서만 2단계에 `AI로 문장 다듬기` 버튼이 나타납니다.
- 버튼을 누를 때마다 **키 주인에게 사용 요금**이 청구됩니다. 키는 파일 안에 들어가지 않습니다.
- AI가 고친 칸은 노란색으로 표시되고, `되돌리기`로 원래 문장에 돌아갈 수 있습니다.
- 목표의 숫자는 바꾸지 못하게 해 두었지만, 꼭 한 번 확인해 주세요.
- 웹 링크로 열었을 때는 AI 기능이 나타나지 않습니다.

## 6. 고치거나 늘리기 (담당자용)

모든 문장은 `프로그램서포터.html` 안에 모여 있습니다. 메모장으로 열어 고칠 수 있습니다.

| 고칠 것 | 찾을 곳 |
|---|---|
| 키워드별 문장 (필요성, 목적, 목표, 회기, 준비물, 기대효과, 설문) | `const KEYWORDS = {` |
| 5대 영역과 중분류 | `const CATS = {` |
| 아동 특성 버튼 | `const TRAITS = [` |
| 결재란 기본 모양 | `const APPROVE_SETS = [` |
| 공통 만족도 문항 | `const COMMON_SURVEY = [` |

- **새 키워드 추가**: 기존 키워드 한 덩어리를 복사해 이름과 문장만 바꾸면 버튼이 하나 더 생깁니다.
- **자동 숫자**: `{k}`(목표 인원), `{p}`(비율), `{n}`(인원), `{c}`(회기 수)는 입력한 값으로 바뀝니다.
- `cat`·`sub`는 영역 대분류·중분류, `prefer: "event"`는 고르면 '하루 행사'로 바꿔 주는 키워드, `timeTable`은 하루 행사 시간표, `extraMethod`는 운영 방법에 꼭 들어갈 안전 문장입니다.
- 새 키워드 문장을 AI로 만들 때 쓰는 프롬프트는 `04 프롬프트 모음` ⑤에 있습니다.

## 7. 기준과 범위

- 서류 칸 순서와 결재란은 센터 실제 서류 `8월 워터파크 프로그램.hwp`(계획서 · 일지 · 평가서)를 따랐습니다.
- 프로그램 형태 3가지, 영역 대·중분류, 만족도 자동 분석은 정보광장 '참참 도우미'를 벤치마킹했습니다. (`02 벤치마킹` 참고)
- **이번 범위에서 제외**: 아동 개인별 관찰일지, 한글(.hwp) 직접 저장, 여러 선생님 공유 저장·로그인, 연간 사업계획서
- 키워드별 활동과 목표 문장은 예시로 작성한 것입니다. 현장 선생님 검토를 거쳐 다듬을 예정입니다.
