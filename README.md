# 프로그램 서포터

지역아동센터 선생님을 위한 **프로그램 계획서 · 일지 · 평가서 작성 도우미**입니다.
2026 천안형 글로벌 인재육성사업 AX 액션러닝 개인과제로 만들었습니다.

프로그램 형태, 분야, 대상, 일정만 버튼으로 고르면 **숫자 목표가 들어간 계획서**를 만들어 줍니다.
같은 내용으로 일지와 평가서도 채워지고, 센터 양식과 결재란 그대로 A4 인쇄할 수 있습니다.

## 해결하려는 문제

| 현장에서 일어나는 일 | 프로그램 서포터가 하는 일 |
|---|---|
| 작년 계획서를 복사해서 날짜만 바꿔 쓴다 | 형태·분야·아동 특성에 맞는 필요성, 목적, 회기별 활동을 새로 만든다 |
| 목표를 숫자로 쓰지 못한다 | "참여 아동 10명(80%) 이상이 ~한다"처럼 숫자 목표를 만들고, 숫자를 정한 근거를 보여 준다 |
| 같은 내용을 계획서·일지·평가서에 세 번 쓴다 | 계획서 내용이 일지와 평가서로 자동으로 이어진다 |

## 바로 써 보기

1. [`프로그램/프로그램서포터.html`](프로그램/프로그램서포터.html)을 내려받습니다. (파일 화면에서 오른쪽 위 다운로드 버튼)
2. 내려받은 파일을 **더블클릭**하면 크롬이나 엣지에서 열립니다. 설치는 필요 없습니다.
3. 자세한 사용법은 [`프로그램/README.md`](프로그램/README.md)에 있습니다.

## 주요 기능

- **3단계 진행**: 내용 고르기 → 계획서 확인 → 서류 만들기. 안내 캐릭터 '별이'가 단계마다 할 일을 알려 줍니다.
- **프로그램 형태 3가지**: 정기 프로그램(회기표), 하루 행사(당일 시간표), 숙박 캠프(날짜별 일정표)
- **5대 영역 18개 키워드**: 보호, 교육, 문화, 정서지원, 지역사회연계 (대분류·중분류)
- **규칙으로 계산**: 목표 인원, 회기 날짜, 출석 목표, 만족도 평균·4점 이상 비율, 예산 합계
- **일지**: 회기별 자동 채움, 사진 8장까지, 끌어서 가리는 모자이크
- **평가서**: 목표별 달성 여부, 만족도 응답 수 → 평균·비율·막대그래프 자동
- **출력**: A4 인쇄, PDF, 워드(.doc) 저장. 결재란은 고르거나 직접 고칠 수 있습니다.
- **AI 문장 다듬기 (선택)**: Claude API 키를 넣은 컴퓨터에서만 켜집니다. 숫자는 바꾸지 못하게 막아 두었습니다.
