## 해결하려는 문제

| 현장에서 일어나는 일 | 프로그램 서포터가 하는 일 |
|---|---|
| 작년 계획서를 복사해서 날짜만 바꿔 쓴다 | 형태·분야·아동 특성에 맞는 필요성, 목적, 회기별 활동을 새로 만든다 |
| 목표를 숫자로 쓰지 못한다 | "참여 아동 10명(80%) 이상이 ~한다"처럼 숫자 목표를 만들고, 숫자를 정한 근거를 보여 준다 |
| 같은 내용을 계획서·일지·평가서에 세 번 쓴다 | 계획서 내용이 일지와 평가서로 자동으로 이어진다 |
| 일지·평가서 의견 칸에 무엇을 쓸지 막막하다 | 관찰·평가 문장 도우미에서 눌러 넣고 고친다 (v2.1) |

## 바로 써 보기

### 인터넷 주소로 쓰기 (GitHub Pages)
main 브랜치에 올리면 자동으로 배포돼요. 처음 한 번만 저장소 **Settings → Pages → Source: GitHub Actions**를 고르면 돼요.
설치 없이 주소만 알려 주면 다른 센터 선생님도 바로 쓸 수 있고, 휴대폰에서도 작성할 수 있어요. 작성한 내용은 각자 브라우저에만 저장돼요.

### 파일로 쓰기
1. 이 저장소의 [`index.html`](index.html)을 내려받아요. (파일 화면 오른쪽 위 다운로드 버튼)
2. 더블클릭하면 크롬이나 엣지에서 열려요. 설치는 필요 없어요. 이름을 `프로그램서포터.html`로 바꿔도 돼요.
3. 자세한 사용법은 [docs/사용설명서.md](docs/사용설명서.md)에 있어요.

### VS Code에서 실행하기 (고칠 때)
1. VS Code에서 이 폴더를 열어요. (추천 확장 Live Server를 설치하라는 안내가 뜨면 설치)
2. 오른쪽 아래 **Go Live**를 누르면 `http://127.0.0.1:5500`으로 열려요. 저장하면 저절로 새로고침돼요.

> AI(Claude Code, Copilot)에게 작업을 맡길 때는 [CLAUDE.md](CLAUDE.md)를 먼저 읽게 하면 돼요. 구조와 지켜야 할 규칙이 정리되어 있어요.

## 주요 기능

- **3단계 진행**: 내용 고르기 → 계획서 확인 → 서류 만들기. 안내 캐릭터 '별이'가 단계마다 할 일을 알려 줘요.
- **프로그램 형태 3가지**: 정기 프로그램(회기표), 하루 행사(당일 시간표), 숙박 캠프(날짜별 일정표)
- **5대 영역 23개 키워드**: 보호, 교육, 문화, 정서지원, 지역사회연계 (대분류·중분류). v2.1에서 환경·기후, 미디어·AI 리터러시, 경제·용돈, 세계문화·다문화, 아동권리·자치 추가
- **규칙으로 계산**: 목표 인원, 회기 날짜, 출석 목표, 만족도 평균·4점 이상 비율, 예산 합계
- **문장 도우미 (v2.1)**: 필요성·목적·기대효과, 일지 관찰 의견, 평가 의견·추후계획 80문장을 눌러서 넣고 빼기
- **점검 (v2.1)**: 1단계 준비 상태, 2단계 '서류 만들기 전 점검'(빈칸·숫자 없는 목표 찾기), 일지 작성 현황
- **평가 지표 맞추기 (v2.2)**: 아동권리보장원 평가 지표(2-1 문화·2-2 교육·2-3 특화) 필수조건과 의견 수렴·아동 참여·지역사회 공유를 점검하고 서류에 근거 문장을 넣어요. 칸마다 **평가위원 팁**
- **가정통신문 (v2.2, 선택)**: 나들이·캠프 등 계획서 내용으로 보호자 안내문과 참가 회신서(건강 상태·비상 연락처·사진 동의)를 만들어요
- **내 프로그램 (v2.3)**: 여러 프로그램을 저장해 열고 지우기, 백업 파일로 다른 컴퓨터에 옮기기
- **2단계 목차 (v2.3)**: 위에 붙는 목차에서 칸마다 ✓/! 확인, 선택 칸은 접어 둠
- **1단계 화면 다듬기 (v2.8)**: '준비 n/4'와 '별이야, 계획서 만들어 줘!' 버튼이 화면 아래에 늘 보이고, 빠진 항목(○ 분야 등)을 누르면 그 질문으로 이동. 휴대폰에서 칩을 칸에 맞춰 정리, 인터넷 없이 열어도 제목이 굵게 보임
- **증빙 기록지 · 보관함 (v2.7)**: 아동자치회 회의록 · 아동 평가회 기록지 양식 인쇄, 다 쓴 기록(사진·스캔·한글)을 프로그램마다 보관
- **우리 센터 문장 (v2.7)**: 자동 초안을 고치지 않은 칸을 표시하고 '우리 센터 문장' 비율을 보여 줘 다른 센터와 문장이 같아지는 것을 막음
- **공휴일 자동 계산 · 백업 알림 (v2.7)**: 해마다 공휴일·대체공휴일을 음력까지 계산, 30일마다 백업 알림·달력(.ics) 매달 알림, 평가 안내 자료(새 평가 지표 PDF) 첨부
- **환류 (v2.6)**: 평가서에 아동 의견·다음에 바꿀 점 → '환류 문장 만들기', 다음 해 계획서에서 '작년 평가 불러오기'로 이어 쓰기
- **한글(.hwpx) 저장 (v2.5)**: 센터 양식(계획서·일지·평가서) 칸에 그대로 채운 한글 파일로 저장
- **시간·쉬는 날 (v2.5)**: 한 번에 40분 / 1시간 / 90분 / 직접 입력, 센터 쉬는 날을 적으면 그 날 회기는 건너뜀
- **새 별이 (v2.5)**: 더 동글동글하게, 기쁠 때 입을 벌리고 반짝이가 나와요. 확인 창도 별이 창으로
- **공휴일 건너뛰기 (v2.4)**: 2026·2027년 공휴일·대체공휴일에 걸린 회기는 다음 날짜로 미루고 '근거'에 알려 줌
- **사진 따로 저장 (v2.4)**: 일지 사진은 브라우저 IndexedDB에 저장 → 사진이 많아도 저장 공간이 차지 않음
- **AI에게 부탁할 글 복사 (v2.4)**: API 키 없이도 계획서 문장 다듬기 부탁 글을 복사해 Claude·ChatGPT에 붙여 넣기
- **넓은 화면 3단계 (v2.4)**: 1280px 이상이면 왼쪽 설정 · 오른쪽 A4 종이를 나란히
- **일지**: 회기별 자동 채움, 사진 8장까지, 끌어서 가리는 모자이크
- **평가서**: 목표별 달성 여부, 만족도 응답 수 → 평균·비율·막대그래프 자동
- **출력**: A4 인쇄, PDF, 워드(.doc) 저장. 결재란은 고르거나 직접 고칠 수 있어요.
- **AI 문장 다듬기 (선택)**: Claude API 키를 넣은 컴퓨터에서만 켜져요. 숫자는 바꾸지 못하게 막아 두었어요.
