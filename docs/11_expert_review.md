## 1. 한 줄 결론

**"선생님이 5가지만 고르면, 평가 지표에 맞는 계획서 → 일지 → 평가서 → 다음 해 환류까지 한 흐름으로 이어지는 도구"**가 되었습니다.
현장에 나눠 쓸 수 있는 수준이지만, **문장은 초안**이라는 점과 **브라우저에만 저장**된다는 점은 꼭 안내해야 합니다.

## 2. 전문가 입장에서 부족했던 점과 이번 보완 (v2.6)

| 관점 | 부족했던 점 | 왜 문제인가 | 보완한 내용 |
|---|---|---|---|
| 평가위원 | 추후계획이 '계속 운영한다'로 끝나기 쉬움 | 2-2 교육 지표 ⑥ **환류의 실시**는 '평가 결과 → 다음 계획 반영'이 보여야 인정 | 평가서에 **환류란?** 안내, **다음에 바꿀 점** 칸, **환류 문장 만들기**(미달성 목표·만족도·아동 의견을 모아 한 문장), 추후계획 **환류 점검**(✓ / !) |
| 평가위원 | 작년에도 한 프로그램인데 작년 평가가 올해 계획에 안 보임 | 환류는 **다음 해 계획서에서 실제로 바뀐 것**이 보여야 함 | 2단계 **⑥ 작년 평가 반영(환류)**: '작년에도 한 프로그램이에요' → 작년 아동 의견 · 올해 바꾼 점 → 계획서 필요성 아래 `※ 전년도 평가 반영(환류)` 문장. '내 프로그램'에 작년 평가서가 있으면 **작년 평가 불러오기** |
| 평가위원 | 작년 의견을 올해 '의견 수렴'으로 착각할 수 있음 | 2026 평가 Q&A: 의견 수렴은 **이번 계획을 위해** 받은 것이어야 함 | 환류 칸 아래 주의 문구: "작년 의견은 환류의 근거, 의견 수렴은 올해 새로. 자치회 안건으로 다시 올리면 둘 다 됨" |
| 센터장 | 아동 평가회에서 나온 **아동의 말**을 적을 곳이 없음 | 아동 참여(⑤)·환류(⑥)의 가장 좋은 근거인데 기록이 흩어짐 | 평가서에 **아동 의견** 칸 → 평가서 '평가' 칸·한글 파일에 `※ 아동 의견` 줄로 들어가고, 다음 해 '작년 평가 불러오기'에 쓰임 |
| 센터장 | 출석률 목표(80%)의 결과를 손으로 계산 | 평가서에 숫자 결과(⑤ 목표의 평가)가 필요 | 일지 '참여자' 칸의 숫자로 **평균 참여 인원·출석률 자동 계산** |
| 센터장 | 나들이·캠프 안전 준비가 운영 방법에 약함 | 외부 활동은 안전 사고가 가장 큰 위험 | 행사·캠프 운영 방법에 **사전 답사 · 차량 점검 · 단체(여행자) 보험 확인** 문장 자동 추가 |
| 개발자 | 한글 파일에 아동 이름이 들어가는데 안내가 없음 | 개인정보가 메일·USB에 남음 | 한글 저장 후 "옮긴 뒤 지워 주세요" 안내 |

v2.4~v2.5에서 먼저 고친 것: 사진 IndexedDB, 공휴일·쉬는 날, 한글(.hwpx) 저장, 시간 4개 항목, 별이 확인 창, 3단계 나란히 보기, 경고색 통일, 키보드 포커스, 자동 테스트 CI ([작업기록](작업기록.md)).

## 3. 장점

| 구분 | 장점 | 근거 |
|---|---|---|
| 쉬움 | 5가지(형태·분야·학년·날짜·특성)만 고르면 초안 완성 | 1단계 준비 상태 표시, 모르는 칸은 비워도 됨 |
| 평가 대비 | 아동권리보장원 평가 지표(2-1 · 2-2 · 2-3)에 맞춘 점검 | 필수조건·의견 수렴·10회기·아동 참여·지역사회 공유·**환류**를 빠짐없이 경고, 칸마다 평가위원 팁 |
| 한 흐름 | 계획서 → 일지 → 평가서 → 가정통신문 → 다음 해 계획까지 같은 내용으로 이어짐 | 한 번 쓴 목표·일정이 모든 서류에 자동으로 들어가고, 평가서가 다음 해 계획의 근거가 됨 |
| 근거가 보임 | 목표 숫자·회기 날짜·만족도·출석률이 **왜 그 값인지** 화면에 적힘 | '근거' 상자, 공휴일·쉬는 날 건너뛴 날 표시 |
| 센터 양식 | 우리 센터 한글 양식(.hwpx) 그대로 저장 + 인쇄 · PDF · 워드 | 센터마다 다시 옮겨 적는 시간이 줄어듦 |
| 비용 · 설치 0 | HTML 파일 1개, 인터넷 주소로도 열림 | 서버·DB·회원가입 없음, 무료(CC BY-NC-SA / MIT) |
| 개인정보 | 작성 내용이 선생님 컴퓨터에만 저장 | 서버로 보내지 않음, 사진 모자이크, AI 부탁 글에는 아동 이름·사진 제외 |
| 품질 관리 | 자동 테스트 7종이 올릴 때마다 실행 | GitHub Actions에서 오류가 나면 실패로 표시 |
| 친근함 | 캐릭터 '별이'가 다음 할 일을 말해 줌 | 막지 않고 알려 주기, 확인 창도 별이 창 |

## 4. 주의점 (다른 선생님께 나눌 때)

| 위험 | 어떤 일이 생길 수 있나 | 크기 | 대응 (지금 / 권장) |
|---|---|---|---|
| 문장이 비슷해짐 | 여러 센터가 같은 초안을 그대로 내면 평가위원이 '복사한 계획서'로 볼 수 있음 | 높음 | 지금: 칸마다 '우리 센터에 맞게 고쳐 주세요' 안내 · 권장: **필요성 근거 숫자와 아동 의견은 꼭 우리 센터 것으로** 바꾸도록 연수 때 강조 |
| 저장 위치 | 브라우저 기록 삭제·다른 컴퓨터 사용 시 내용이 안 보임 | 높음 | 지금: 저장 공간 표시, 백업 파일 받기·불러오기 · 권장: 한 달에 한 번 백업, 끝난 프로그램은 한글 파일로 보관 |
| 평가 기준 변화 | 평가 지표·공휴일은 해마다 바뀜 | 중간 | 지금: 2026 기준 · 2027년까지 공휴일 · 권장: 매년 12월 `HOLIDAYS`와 [10_evaluation.md](10_evaluation.md) 갱신 |
| 의견 수렴 · 환류 '증빙' | 도구에 체크해도 실제 회의록·평가회 기록이 없으면 인정 안 됨 | 중간 | 지금: 팁에 '기록을 남겨요' 안내 · 권장: 자치회 회의록·아동 평가회 기록지를 함께 보관 |
| 개인정보 파일 | 백업·한글·워드 파일에 아동 이름이 들어감 | 중간 | 지금: 저장할 때마다 안내 · 권장: 공용 PC에서는 쓰고 나서 '내 프로그램' 지우기 |
| 한글 저장 범위 | 사진은 한글 파일에 안 들어감, 결재란은 2칸까지 | 낮음 | 지금: 안내 문구 · 권장: 다음 버전에서 사진 넣기 |
| AI 기능 | API 키 요금은 키 주인에게 청구, AI 문장은 사실 확인 필요 | 낮음 | 지금: 키 없이 '부탁 글 복사' 가능, 숫자 그대로인지 확인 안내 |
| 판매 금지 | CC BY-NC-SA: 무료로 나누는 것은 되지만 판매는 안 됨 | 낮음 | 화면 맨 아래 이용 조건 표시 |
