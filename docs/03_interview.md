다 쓰고 1분만 다시 봅니다.

> * 네/아니오로 끝나는 질문은 고칩니다. "불편하신가요?"가 아니라 "어느 단계에서 가장 오래 걸립니까?"
> * 내 아이디어를 설명하는 문장은 뺍니다. "제가 자동화하면 좋으시겠죠?"는 질문이 아닙니다.
> * 내가 묻고 싶은 것을 묻지 말고, 상대가 하고 싶은 말을 듣습니다.

### **회차 : 1 / 일시 : 2026-11-03 / 대상 : 현장 자료 검토**

인터뷰 전에 센터의 실제 서류 양식 「8월 워터파크 프로그램」(담당자 박정환 작성)을 검토했습니다.

| 항목 | 내용 |
| :---- | :---- |
| **자료에서 확인한 내용 (그대로)** | 세 서류 모두 결재란은 **담당자 · 시설장** / 계획서 칸: 프로그램명(문화프로그램), 제목, 담당자, 일시, 대상, 장소, 준비물, 필요성, 목적, 목표, 프로그램 내용, 기대효과, 프로그램 예산, 프로그램 평가방법 / 일지 칸: 프로그램명, 제목, 담당자, 장소, 작성일자, 진행자, 준비물, 참여자, 진행내용, 담당자 의견, 사진 / 평가서 칸: 계획서 칸 + 참여아동, 세부 프로그램 내용, 평가, 담당자 의견, 추후계획 / 목표: '1. 워터파크 안전수칙을 숙지하여 안전한 물놀이를 할 수 있다. 2. 워터파크 내에 있는 시설들을 3가지 이상 즐길 수 있다. 3. 다치지 않고 안전한 물놀이를 즐긴다.' / 필요성: 아동자치회의에서 장소를 정했고, 새로 입소한 아동이 물놀이를 갈 기회가 없었다. |
| **새로 알게 된 사실** | 세 서류가 같은 칸(제목·담당자·일시·장소·준비물·필요성·목적·목표)을 많이 나눠 쓴다 → 자동 연결의 효과가 크다. '프로그램명' 칸에는 이름이 아니라 **분류**(문화프로그램)를 쓴다. 정기 수업뿐 아니라 **하루 외부 체험**도 계획서 대상이다. 프로그램 내용, 예산, 평가방법 칸이 비어 있었다 → 쓰기 어려운 칸이다. |
| **틀렸던 가정** | 정기 회기 프로그램만 생각했다 → 하루 행사도 많다. 결재란을 '담당·센터장'으로 가정했다 → 실제는 '담당자·시설장'이고 센터마다 다를 수 있다. '아동일지'를 아동 개인별 일지로 생각했다 → 이번 서류는 '프로그램 일지'다. |
| **01 PRD에 반영할 것** | F2 일지·평가서 자동 연결, F3 센터 양식 그대로 출력, 프로그램 형태 3가지, 결재란 직접 고치기, 목표 예시를 문제 장면 ②로 사용 → ✅ v2 반영 |
