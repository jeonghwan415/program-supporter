# **04 아키텍처**

**개인 프로젝트**
과제명: 지역아동센터 프로그램 서포터 · 기준: v2.5 (2026-11-14)
PRD의 핵심 기능을 입력 → 처리 → 출력으로 나눠 봅니다. **규칙으로 할 일과 AI에게 맡길 일을 구분합니다.** 함수·상수 이름은 [../CLAUDE.md](../CLAUDE.md)에 더 자세히 있어요.

핵심 기능:
1\. 계획서 자동 생성 ─ 형태·분야·학년·일정·아동 특성 → 규칙 → 필요성·목적·숫자 목표(근거)·일정·운영 방법·기대효과
2\. 일지·평가서 자동 연결 ─ 계획서 내용 → 회기별 일지, 평가서(목표 달성·만족도 계산)
3\. 센터 양식 그대로 출력 ─ 칸 순서·결재란 그대로 A4 인쇄·PDF·워드

| 기능 | 화면 (06 와이어프레임) | 입력 | 처리 | 출력 |
| ----- | ----- | ----- | ----- | ----- |
| 계획서 자동 생성 | 01~03 내용 고르기, 04~07 계획서 확인 | 형태, 키워드(23개 또는 직접), 학년, 인원, 시작일·회기·주기·시간 또는 박 수, 아동 특성 9개, 메모, 요청 | `buildPlan()`: 키워드 문장에 숫자 채우기({k}=올림(인원×비율)), 회기 날짜 계산, 활동 고르기, 학년·형태·특성·요청으로 운영 방법 조립 | 고칠 수 있는 계획서 + 목표마다 '근거' |

## 구조 그림

```
[선생님 브라우저 (센터 PC · Edge/Chrome / 휴대폰)]
   index.html  ← 프로그램 전체 (HTML+CSS+JS 한 파일, 외부 라이브러리 없음)
     ├─ KEYWORDS · TRAITS · *_MORE · *_PHRASES   문장과 규칙 (파일 안)
     ├─ localStorage  ps.draft · ps.info · ps.ui · ps.aiKey   (이 브라우저에만)
     └─ (선택) Claude API ── 키가 있을 때만, 문장 다듬기
             │ 인쇄 / 파일 받기
             ▼
        A4 계획서·일지·평가서·만족도 조사지 / PDF / .doc

[작성자 PC · VS Code (만들 때만)]
   공개 자료 ─ Firecrawl 크롤링 ─→ 발췌문 (저장소에 올리지 않음)
             ─ tools/analyze_vocabulary.py (Kiwi 형태소 + wordcloud) ─→ data/vocabulary/빈도분석.json, docs/images/08_vocabulary/*.png
             ─ 사람이 쉬운 말로 새로 씀 ─→ index.html의 KEYWORDS · 문장 도우미
   git push main ─→ GitHub Actions(.github/workflows/pages.yml) ─→ GitHub Pages
```

## 규칙 vs AI

| 규칙(코드·문장 모음)으로 하는 일 | AI에게 맡기는 일 |
| :---- | :---- |
| 목표 인원·출석 목표·회기 날짜·만족도·예산 계산 | 계획서 문장 다듬기 — **선택 기능**, 키가 있을 때만, 숫자 보호 |
| 키워드 문장·회기 활동·운영 방법 조립 | 새 키워드 문장 초안 — **개발할 때만** (07 프롬프트 ⑤), 사람이 검토 후 넣음 |
| 문장 도우미 넣기·빼기, 서류 점검 | 어휘 분석 결과로 문장 초안 — **개발할 때만**, 사람이 검토 |

**기본 기능은 AI를 부르지 않아요.** 비용이 들지 않고, 누를 때마다 같은 결과가 나오고, 아이 정보가 밖으로 나가지 않아요.
