# **09 현장 테스트 준비 (03 인터뷰 회차 2)**

**개인 프로젝트**
과제명: 지역아동센터 프로그램 서포터 · 기준: v2.2 (2026-11-14)
PRD 목표 "**서류 1세트 작성 시간 50% 이상 단축**"을 확인하는 테스트입니다. 결과는 [03_interview.md](03_interview.md) 회차 2 칸에 옮기고, [07 프롬프트](07_prompts.md) ③으로 PRD를 고칩니다.

| 방법 | 대상 | 걸리는 시간 | 준비물 |
| :---- | :---- | :---- | :---- |
| A. 만나서 시연 | 선생님 3명 (한 명씩) | 1명당 약 40분 | 노트북(크롬·엣지), 이 문서 인쇄본 3부, 시계(휴대폰 스톱워치) |
| B. 카톡으로 혼자 해 보기 | 단톡방 선생님들 | 1명당 약 15분 | 안내 글(아래), 설문(구글 폼) |

> 두 방법 모두 **실제 아동 이름·사진은 쓰지 않습니다.** 예시 아동은 '○○ 아동'으로만 씁니다.

## A. 만나서 시연

### A-1. 진행 순서 (40분)

| 순서 | 시간 | 하는 일 | 진행자가 할 말 (예) |
| :---- | :---- | :---- | :---- |
| ① 인사 | 2분 | 목적과 녹음 동의 | "도구를 평가받는 게 아니라, 선생님이 실제로 어떻게 쓰시는지 보려고 해요. 틀린 답은 없어요." |
| ② 질문 | 15분 | 03 인터뷰 질문지 ①~⑦, 추가 1·2 | 질문지 그대로. 네/아니오 질문은 하지 않기 |
| ③ 기존 방식 | 10분 | 과제 X를 **평소 방식**으로 계획서만 작성 (한글·작년 파일 등) | "평소처럼 해 주세요. 10분이 되면 멈출게요." |
| ④ 프로그램 서포터 | 10분 | 같은 과제 X를 **프로그램 서포터**로 계획서 + 일지 1장 + 평가서 | "설명 없이 해 보세요. 막히면 소리 내어 말해 주세요." (도와주지 않기) |
| ⑤ 질문 | 3분 | 추가 3·4 + 설문 | 아래 A-3 설문 |

- ③과 ④의 **순서를 사람마다 바꿉니다** (1번 선생님 ③→④, 2번 ④→③, 3번 ③→④). 두 번째에 익숙해지는 효과를 줄이려고요.
- 10분 안에 못 끝내면 그 시점까지 한 칸 수를 적습니다.

### A-2. 과제 카드 (선생님께 보여 줄 것)

> **과제 X** — 다음 달부터 **초3~초5 아동 10명**과 **매주 화요일 60분, 8회** '**환경·기후**' 프로그램을 합니다. 아이들 중에 집중 시간이 짧은 아동이 있어요. 계획서를 써 주세요. (프로그램 서포터로 할 때는 일지 1회기와 평가서까지)

### A-3. 기록지 (선생님 1명당 1장)

| 항목 | 기록 |
| :---- | :---- |
| 선생님 | ①  ②  ③ (이름 대신 번호) · 경력 ___년 · 나이대 ___ |
| 순서 | □ 기존 → 서포터  □ 서포터 → 기존 |
| 기존 방식: 계획서 완성 시간 | ___분 ___초 (미완성이면 채운 칸 ___ / 14칸) |
| 서포터: 계획서 완성 시간 | ___분 ___초 |
| 서포터: 일지 1장 | ___분 ___초 |
| 서포터: 평가서 | ___분 ___초 |
| 서포터: 도움을 요청한 횟수 | ___번 (어디서: __________) |
| 목표에 숫자가 있었나 | 기존 □ 있음 □ 없음 / 서포터 □ 있음 |
| 문장 도우미를 눌렀나 | □ 필요성 □ 목적 □ 기대효과 □ 일지 □ 평가 □ 추후계획 □ 안 누름 |
| '고치러 가기'를 눌렀나 | □ 예 □ 아니오 |
| 멈칫한 곳 (그대로 적기) | |
| 들은 말 (그대로 적기) | |

**계산:** 단축률 = (기존 계획서 시간 − 서포터 계획서 시간) ÷ 기존 계획서 시간 × 100. **3명 평균 50% 이상이면 목표 달성.**
일지·평가서는 기존 방식 시간을 따로 재지 않으므로, 질문 ⑥("1세트에 지금 몇 분")의 답과 비교합니다.

### A-4. 시연 후 설문 (종이, 5점 척도)

| 번호 | 질문 | 1 전혀 아니다 ~ 5 매우 그렇다 |
| :---- | :---- | :---- |
| 1 | 설명 없이도 다음에 무엇을 할지 알 수 있었다 | 1 2 3 4 5 |
| 2 | 만들어진 계획서를 조금만 고쳐서 쓸 수 있겠다 | 1 2 3 4 5 |
| 3 | 목표의 숫자와 '근거'가 이해하기 쉬웠다 | 1 2 3 4 5 |
| 4 | 문장 도우미가 의견 칸을 쓰는 데 도움이 되었다 | 1 2 3 4 5 |
| 5 | 인쇄된 서류가 우리 센터 양식과 비슷했다 | 1 2 3 4 5 |
| 6 | 다음 프로그램 서류도 이것으로 쓰겠다 | 1 2 3 4 5 |
| 7 | (서술) 가장 헷갈렸던 버튼이나 글자는? | |
| 8 | (서술) 그대로 쓰기 어려운 문장이나 키워드는? | |
| 9 | (서술) 꼭 있었으면 하는 기능 하나는? | |

**PRD 목표 "다음에도 쓰겠다 80% 이상"** = 6번에 4·5점 응답 비율.

## B. 카톡으로 혼자 해 보기

### B-1. 단톡방 안내 글 (복사해서 보내기)

```
선생님들, 안녕하세요 😊 제가 만든 '프로그램 서포터'를 한 번 써 봐 주실 수 있을까요?
계획서·일지·평가서를 버튼 몇 번으로 만들어 주는 도구예요. (무료, 설치·로그인 없음)

👉 https://jeonghwan415.github.io/program-supporter/
(PC 크롬·엣지 권장, 휴대폰도 작성 가능)

해 보실 것 (10분쯤)
1. 다음 달 실제로 할 프로그램 하나로 계획서를 만들어 보기
2. 일지 1장, 평가서 1장도 눌러 보기 (문장 도우미 써 보기)
3. 끝나고 설문 3분 👉 [구글 폼 주소]

⚠ 아이 실제 이름·사진은 넣지 말아 주세요. (작성 내용은 선생님 컴퓨터에만 저장돼요)
솔직한 의견이 제일 큰 도움이 돼요. 감사합니다!
```

### B-2. 구글 폼 문항

| 번호 | 질문 | 형식 |
| :---- | :---- | :---- |
| 1 | 센터에서 맡고 계신 일 | 객관식: 센터장 / 생활복지사 / 기타 |
| 2 | 어떤 키워드로 해 보셨나요? | 단답 |
| 3 | 평소 계획서 1장 쓰는 데 걸리는 시간 | 객관식: 10분 이내 / 10~30분 / 30분~1시간 / 1시간 이상 |
| 4 | 프로그램 서포터로 계획서까지 걸린 시간 | 객관식: 5분 이내 / 5~10분 / 10~20분 / 20분 이상 |
| 5~10 | A-4 설문 1~6번 | 선형 배율 1~5 |
| 11 | 가장 헷갈렸던 버튼이나 글자 | 장문 |
| 12 | 그대로 쓰기 어려운 문장·키워드 | 장문 |
| 13 | 새 키워드 중 센터에서 해 볼 것 | 체크박스: 환경·기후 / 미디어·AI 리터러시 / 경제·용돈 / 세계문화·다문화 / 아동권리·자치 / 없음 |
| 14 | 꼭 있었으면 하는 기능 | 장문 (예: 한글 파일 저장, 희망이음 요약) |

> 3·4번은 범위로 묻기 때문에 정확한 단축률은 A(시연)로 확인합니다. B는 많은 선생님의 첫인상과 헷갈린 곳을 모으는 용도예요.
