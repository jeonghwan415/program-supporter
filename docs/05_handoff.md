# **05 handoff**

**개인 프로젝트**
과제명: 지역아동센터 프로그램 서포터 · 기준: v2.8 (2026-11-18)
개발을 이어서 하거나 운영할 때 정해 둔 것. 모르는 것은 **미확인**으로 적고 [03 인터뷰](03_interview.md) 질문으로 옮깁니다.

**한 줄 요약:** HTML 파일 1개로 된 무료 도구. 버튼으로 고른 내용을 규칙으로 계산해 계획서를 만들고, 같은 내용으로 일지·평가서를 채워 센터 양식대로 인쇄한다. 서버와 DB가 없다.

- 저장 위치 > **작성 내용은 선생님 컴퓨터의 브라우저(localStorage)에만** 저장. `ps.draft`(input + plan, 일지·평가서·사진 포함), `ps.info`(센터·담당자 이름), `ps.ui`(서류 탭·결재란·조사지), `ps.aiKey`(AI 키). 서버·DB 없음. 서류는 인쇄·PDF·워드(.doc)로 남김. v2.1의 문장 도우미·점검은 새 저장 항목이 없고, v2.2의 평가 지표(`ind`·`inAnnual`·`opinion`·`childPlan`·`childEval`·`share`)와 가정통신문(`notice`)은 `ensurePlan()`이 빈 값으로 채워서 **예전에 쓰던 내용도 그대로 열림**. '센터 정보 지우기'는 `ps.info`, '지우고 새로 쓰기'(두 번 누름)는 `ps.draft`를 지움
- 여러 프로그램 (v2.3) > `ps.plans`에 프로그램마다 `{input, plan, updated}`, `ps.cur`에 지금 것. 예전 `ps.draft`의 계획서는 처음 열 때 자동으로 목록에 옮김. 백업 파일 `{app:"program-supporter", v:1, info, plans}` — 불러오면 같은 id는 더 최근 것을 남김. 저장 공간(약 5MB) 사용률을 1단계에 표시
- 사진 (v2.4) > 사진은 IndexedDB `program-supporter` / `photos`에 저장하고 plan에는 `"idb:<id>"`만 남김. 예전 dataURL 사진은 열 때 `migratePhotos()`가 옮김. 백업 파일에는 `inlinePhotos()`로 사진을 다시 넣어 한 파일로 옮겨짐. 프로그램을 지우거나 다시 만들면 그 사진도 지움
- 공휴일 (v2.4) > `HOLIDAYS`(2026·2027, 인사혁신처 발표 기준)에 걸린 회기는 건너뜀. **해마다 12월에 다음 해를 추가**해야 함 (선거일 등 임시공휴일 포함)
- 여러 탭 (v2.4) > 같은 프로그램을 두 탭에서 고치면 나중 저장이 덮어씀. `storage` 이벤트로 경고만 하고 합치지는 않음
- 공휴일 (v2.7) > `holidaysFor(year)`가 해마다 계산 (`Intl.DateTimeFormat('ko-KR-u-ca-dangi')`로 음력). 브라우저가 음력을 못 하면 `HOLIDAYS_FALLBACK`(2026·2027) 사용. 선거일 등 임시공휴일은 `HOLIDAY_EXTRA`에 추가. 법이 바뀌면(새 공휴일·대체 규칙) `holidaysFor()`만 고치면 됨
- 증빙·자료 (v2.7) > plan.`files[]` = {ref:'idb:…', kind:minutes|childeval|other, name, type, size, added}, 백업 시 dataURL로 펼침. 평가 안내 자료는 `ps.guides`(백업에 안 넣음, 다시 받으면 됨), `ps.lastBackup`, `ps.guideMonth`. 원문 초안은 plan.`base`(고유성 점검용)
- 환류 (v2.6) > plan에 `prev{on,voice,change,from}`, evalr에 `childVoice`·`change` (없으면 `ensurePlan()`이 채움). `feedbackLine()`이 계획서·평가서 필요성 아래에 문장을 붙임. '작년 평가 불러오기'는 '내 프로그램'의 다른 프로그램 중 평가서에 아동 의견·추후계획이 있는 것만 보여 줌(같은 키워드 먼저)
- 한글 저장 (v2.5) > `HWPX_TPL` = 센터 양식 hwpx 파일들(JSON)을 gzip+base64로 넣은 것. `DecompressionStream`으로 풀고 `DOMParser`로 표 3개(계획서·일지·평가서)의 칸을 `cellAddr`(열,행)로 찾아 채움 → `zipStore()`로 압축 없이 묶음(mimetype 맨 앞). 양식을 바꾸려면 새 hwpx의 값 칸을 비워 다시 넣고 `hwpxCells()`의 칸 위치를 맞추면 됨. 사진(BinData)은 아직 안 넣음
- 1단계 화면 (v2.8) > '준비 n/4'와 만들기 버튼 줄(`.makebar`)이 화면 아래에 붙어 있음(`position: sticky`, 인쇄 안 됨). 빠진 항목은 버튼(`data-goto`)이라 누르면 그 질문 카드로 이동하고 첫 버튼에 포커스. 평가 안내 자료 카드는 ⑤ 아래로 옮기고, 매달 확인할 때가 되면 상자를 펼치지 않고 접힌 제목 줄에 '이달 확인'(주황, `.optional.due`)만 보여 줌. 질문 번호(1~5) 칸은 노랑, 글 속 링크는 남색(`a:not(.btn)`). 휴대폰(640px 이하)에서는 분야·아동 특성 칩 2칸, 학년 4칸, 아래 줄에는 빠진 항목만. 새 저장 항목 없음
- 권한 > 로그인 없음. 파일이나 사이트를 가진 사람 누구나 씀. AI 키는 입력한 브라우저에만 남고 파일에 들어가지 않음
- API·DB > DB 없음. 선택 기능으로 Claude API(POST /v1/messages, 모델 claude-opus-5-5, JSON 형식 고정, effort low)를 브라우저에서 직접 부름. 다른 페이지 안(iframe)에서 열리면 AI·인쇄·저장을 숨김. 외부 라이브러리 없음. 글꼴은 Google Fonts(제목 Jua, 본문 Noto Sans KR)에서 받고, 인터넷이 없으면 맑은 고딕으로 보임 — v2.8부터 제목 글꼴을 못 받으면 `html.no-jua`를 붙여 제목을 굵게
